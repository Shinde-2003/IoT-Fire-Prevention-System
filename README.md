# IoT-Fire-Prevention-System
An IoT-based fire prevention and safety system developed in Cisco Packet Tracer using smart sensors for fire detection, monitoring, and automated alert generation.

## Overview
The IoT Fire Prevention System is a Cisco Packet Tracer project designed to detect potential fire hazards using smart sensors and automated alert mechanisms. The system continuously monitors environmental conditions and provides real-time notifications when fire-related risks are detected.
